被指出的问题：

1. `qpos` 是位置（position），`qvel` 是速度（velocity）
   它们是**同一个时刻**的两个不同量，不是"前"和"后"
2. 脚本里 `robot0_gripper_qpos` 只打印了一次，而且是在循环开始前
   那是**动作前**的状态，没有动作后的状态
3. 证明"变化"需要两个数：before 和 after
   一个数证明不了变化

## 三、这轮学到的核心教训

1. **qpos 和 qvel 不是前后关系**
   - qpos = 关节位置（现在是哪）
   - qvel = 关节速度（现在动多快）

2. **证明变化需要两个测量**
   ```text
   变化 = 动作后的值 - 动作前的值
   ```
   只有一个测量值，证明不了任何变化。

3. **动作值和位置值是两种不同的数**
   ```text
   动作第 7 位 = -1.0、+1.0、0.0   → 这是发给夹爪的命令
   robot0_gripper_qpos = [0.0208, -0.0208] → 这是夹爪手指的关节位置
   ```
   一个是输入，一个是状态。单位也不同。

4. **复现很重要**
   改完就跑、跑完就改回去、不留记录，等于没做。
   每次实验要能重新做一遍。

## 四、正确答案（导师在 2 次尝试后给出）

```python
gripper_before = np.array(obs["robot0_gripper_qpos"], dtype=float)

```

## 八、术语小抄

```text
qpos   = position，位置：手指关节现在转到了哪里（弧度或模型单位）
qvel   = velocity，速度：手指关节现在动得多快
action = 动作：发给夹爪的命令（-1 开 / +1 关 / 0 保持）
delta  = 差值：after - before，衡量"变了多少"
观测   = 环境返回的状态，比如 robot0_gripper_qpos
命令   = 我们发给环境的输入，比如动作第 7 位
```
