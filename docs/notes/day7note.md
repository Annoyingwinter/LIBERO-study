## 三、诊断过程（五步法实录）

```text
1. 看列 → init_state, success, episodes, rate
2. 看分布 → 大多数 80~100%，异常是那 4 个
3. 找异常 → 13/1/2/10
4. 提假设 → 假设1："碗位置离示范远" → 被反例打穿
            （1 号和 11 号碗位置几乎一样，一个 40% 一个 100%）
            假设2："ramekin 挤" → 被反例打穿
            （13 号间隙 16.7cm，38 号更挤 14.6cm 却 90%）
            假设3："cookies 挡路" → 被反例打穿
            （13 号离 cookies 反而更远）
5. 换证据源 → 录像（位置表给假设，录像给答案）
```

## 四、录像诊断的结论（7 段失败视频逐帧看）

```text
够到碗：7/7（远距离定位没问题）
夹住过：0/7（闭合瞬间碗不在两指之间）
死因一句话：不是眼睛瞎（认得出碗），是手抖（毫米级对准学不精）
= 抓取瞬间的精细定位失败
```

## 五、重要教训（研究方法）

```text
1. 静态位置表只给假设，录像给死因
2. 假设必须撞数据：三个几何假设全被"对照组"打穿
   （对照组法：找一个"几何相似但成功"的考场比）
3. 同一个考场两次测结果不同（1/10 vs 3/10）
   = GPU 蝴蝶效应的活例证，再次证明要多次测量
```
